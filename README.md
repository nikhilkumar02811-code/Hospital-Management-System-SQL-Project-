🏥 Hospital Management System (SQL Project)

🚀 Project Highlights

* Designed relational database with **5 interconnected tables**
* Performed data analysis using **JOINs, Aggregations, and Subqueries**
* Analyzed **patient data, doctor workload, and treatment records**
* Applied **DML operations (INSERT, UPDATE, DELETE)** for data handling


📌 Overview

A SQL-based system to manage hospital data including patients, doctors, appointments, and treatments.
This project demonstrates **end-to-end database design and data analysis using real-world healthcare scenarios**.


🛠️ Tech Stack

* SQL Server (SSMS)


🗂️ Project Structure

```text
schema.sql   → Tables + data  
queries.sql  → Analysis queries  
README.md  
```

📊 Key Analysis

* 👨‍⚕️ Doctor-wise appointment count
* 🧑‍🤝‍🧑 Patient distribution (gender-based)
* 📅 Appointment trends by date
* 💊 Treatment and diagnosis analysis
* ❌ Identification of doctors with no appointments

---

🧠 SQL Concepts Used

* Joins (INNER JOIN)
* Aggregations (COUNT, GROUP BY)
* Subqueries
* Date filtering (MONTH, YEAR)
* DML operations (INSERT, UPDATE, DELETE)


🚀 How to Run

1. Run `schema.sql`
2. Run `queries.sql`


📌 Conclusion

This project showcases strong SQL fundamentals including **database design, relational mapping, and data analysis**, making it relevant for real-world data-driven applications.
